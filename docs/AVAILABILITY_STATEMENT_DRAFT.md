# Draft statements for the manuscript

## Data availability (replace the placeholder in the Data availability section)

The datasets analysed in this study are publicly available. Cell-type-specific cis-eQTL data were
obtained from the OneK1K cohort (https://onek1k.org/). Myasthenia gravis GWAS summary statistics were
obtained from the published European-ancestry meta-analysis (GWAS Catalog GCST90432156). Immune eQTL
records used for the audit were obtained from the DICE database (https://dice-database.org/).
Phenome-wide and drug annotation information was obtained from the NHGRI-EBI GWAS Catalog, the Open
Targets Platform, DSigDB and Enrichr. The peripheral blood single-cell RNA sequencing dataset
generated in this study (three healthy controls and four patients with myasthenia gravis) has been
deposited in the NCBI Gene Expression Omnibus under accession **GSE______** [reviewer access token:
__________]. All summary-level results generated in this study, including genetic instruments, MR
results, colocalisation results, single-cell results, PheWAS records and drug annotations, are provided
in the Supplementary Tables and in the analysis repository (https://github.com/Fan-ane/MG_scMR_2026).

## Code availability (this section is currently empty)

All analysis code is available at https://github.com/Fan-ane/MG_scMR_2026
(archived at https://doi.org/10.5281/zenodo.______): the genetic pipeline (instrument selection,
single-instrument Wald ratios, colocalisation, DICE audit, PheWAS and drug annotation), the single-cell
pipeline (quality control, donor-level pseudobulk, exact donor-label permutation and virtual knockout),
the revision-stage figure and table code, and the LD-based locus consolidation analysis.
